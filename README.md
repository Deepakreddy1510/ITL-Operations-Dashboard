# ITL Branch Manager Dashboard

A modern web dashboard for Integrated Thermoplastics Limited (ITL), designed for branch managers to monitor daily operations.

## Features

- Dashboard with KPIs and charts
- Customer management
- Quotations
- Orders
- Inventory
- Purchases
- Reports
- Notifications
- Multi-user JWT authentication
- Excel/CSV import

## Tech Stack

- Next.js 15
- TypeScript
- Tailwind CSS
- Prisma
- SQLite
- JWT Authentication

## Installation

```bash
npm install
npx prisma db push
npm run db:seed
npm run dev
```
